# @flylab/app

Next.js (App Router) front-end for Real Fly Lab — the real fruit fly brain:
the FlyWire connectome and the Shiu et al. 2024 LIF model, with fully
precomputed, honestly labeled experiments.

## Stack

- Next.js (App Router, static export) + TypeScript
- Tailwind CSS v4
- three.js — real 139,248-neuron soma point cloud from `public/data/neurons.bin`
- Zustand (UI state: loading phase, selected condition)

## Real data

`public/data/` is generated by `pipelines/` at the repo root:

- `graph-meta.json` — provenance, model parameters, label dictionaries,
  coordinate-space note (raw FlyWire nm, NOT atlas co-registered)
- `neurons.bin` — soma positions + label indices (FLYN v1 format)
- `ids.txt` — exact decimal string root IDs (line i = node i)
- `traces-index.json` / `trace-*.json` — offline model runs per condition
- `gate.json` — paper-reproduction checks (baseline silence, sugar→MN9,
  bitter suppression, shuffled control…)

Regenerate with `pnpm bundle` and `pnpm traces` from the repo root.

## Develop

```bash
pnpm install
pnpm dev          # http://localhost:3000
```

## Build (static export)

```bash
pnpm build        # honours NEXT_PUBLIC_BASE_PATH (e.g. /flydynasty for GitHub Pages)
```

Output goes to `out/`. Deployed to GitHub Pages via
`.github/workflows/deploy-pages.yml`.

## Routes

- `/` — the connectome point cloud (drag to orbit, wheel to zoom), experiment
  dock listing the precomputed model runs with canonical-trial rasters, live
  status from graph-meta.json
- `/about` — methodology, what's real vs simulated, the reproducibility gate,
  data licensing
